# 제1장: 바이브 코딩으로 시작한 무모한 도전

## 1. 시작: 아이디어는 하나, 코드는 엉망
우리의 시작은 단순했습니다. "가장 안전하면서도 멋진 도어락을 만들자." 하지만 팀원들의 개발 환경도, 언어 숙련도도 제각각이었습니다. 우리는 여기서 '바이브 코딩(Vibe Coding)'이라는 방식을 도입했습니다.

단순히 문법을 하나하나 공부하는 것이 아니라, AI와 대화하며 시스템의 '바이브(흐름)'를 먼저 이해하고, 큰 뼈대를 빠르게 구축하는 방식이었습니다.

## 2. 우리가 한 일: MVP(최소 기능 제품) 구축
처음 3일 동안 우리는 다음과 같은 기본 기능을 한곳에 몰아넣어 동작하게 만들었습니다.

- **아두이노 시리얼 전송:** 카드를 대면 UID가 화면에 찍히게 만들었습니다.
- **파이썬 서버 기초:** 아두이노가 보낸 글자를 받아서 "Hello"라고 응답하는 수준부터 시작했습니다.
- **YOLOv8 첫 로드:** 카메라 영상에서 '사람'을 인식하는 것만으로도 우리는 환호했습니다.

## 3. 깨달음: 통합의 어려움
각각의 기능은 잘 돌아갔지만, 이를 하나로 합치는 과정에서 수많은 에러가 발생했습니다. 시리얼 포트 점유 문제, 영상 처리로 인한 메인 루프 멈춤 현상 등이 우리를 괴롭혔습니다.

하지만 우리는 포기하지 않고 `main.py`라는 오케스트레이터를 만들어 모든 신호를 통제하기 시작했습니다. 이것이 우리 프로젝트의 진정한 심장이 되었습니다.
