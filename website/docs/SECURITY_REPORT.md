# 스마트 도어락 시스템 보안 점검 및 패치 보고서

## 1. 개요
본 문서는 삼육대학교(SYU) 2FA 스마트 도어락 프로젝트에서 발견된 치명적인 보안 취약점(Insecure Deserialization)과 이에 대한 패치 내용을 보고하기 위해 작성되었습니다.

## 2. 보안 취약점 내용
도어락 서버는 얼굴 인식 데이터를 처리하기 위해 과거에 `pickle`이라는 파이썬 라이브러리를 사용했습니다. `pickle`은 데이터를 저장하고 불러오는 편리한 도구지만, 신뢰할 수 없는 데이터가 입력될 경우 치명적인 **원격 코드 실행(RCE)** 공격을 받을 수 있습니다.

쉽게 말해, 해커가 악의적인 코드가 담긴 얼굴 데이터를 도어락 서버에 전송하면, 서버가 이 데이터를 읽어들이는 과정에서 해커의 코드가 그대로 실행되어 서버 전체의 통제권을 빼앗길 수 있는 매우 위험한 취약점입니다. 비록 이 기능이 기본적으로 비활성화(`ALLOW_LEGACY_FACE_PICKLE = False`)되어 있었지만, 코드가 서버 내에 존재한다는 것만으로도 잠재적인 위험 요소였습니다.

## 3. 해결 방안 (패치 내용)
이러한 위험을 완전히 제거하기 위해 다음과 같은 조치를 취했습니다.

*   **위험한 코드 완전 삭제**: `server/vision_ai.py`에서 `pickle` 모듈과 관련된 모든 코드를 영구적으로 삭제했습니다.
*   **환경 변수 제거**: 더 이상 설정 파일이나 환경 변수를 통해서도 이 레거시(과거) 방식을 켤 수 없도록 `server/config.py`에서 `ALLOW_LEGACY_FACE_PICKLE` 관련 항목을 모두 제거했습니다.
*   **안전한 방식만 허용**: 이제 모든 얼굴 데이터는 안전한 접두사 기반의 특수 데이터 형태(`FACE128F64:`)만 허용하며, 형식에 맞지 않는 데이터는 즉각적으로 거부되도록 방어 코드를 추가했습니다.

## 4. 검증 결과
모든 테스트 코드를 점검 및 수정하였으며, 자동화된 테스트(`unittest`)를 통해 레거시 데이터가 완벽하게 차단됨을 확인했습니다. 이번 패치로 인해 기존 정상적인 작동에는 아무런 영향이 없음을 보장합니다.
