# 아두이노 모듈 설명 (Arduino Hardware)

도어락 시스템의 하드웨어 제어는 Arduino를 통해 이루어집니다. `arduino/` 디렉토리에 있는 코드는 C++ 기반이며 각종 센서 입력과 액추에이터 제어를 처리합니다.

## 핵심 기능 (`doorlock.ino`)

### 1. 하드웨어 컴포넌트 제어
Arduino는 다음 하드웨어 모듈과 연동되어 동작합니다:
- **MFRC522 (NFC/RFID 리더기):** 사용자의 NFC 태그나 카드를 인식하여 UID를 읽어옵니다. 1차 인증 수단 중 하나입니다.
- **4x4 Keypad:** 사용자가 PIN 번호를 입력할 수 있도록 입력을 받습니다. 또 다른 1차 인증 수단입니다.
- **Relay (릴레이 모듈):** 전자 도어락(솔레노이드 또는 마그네틱 락)의 전원을 제어하여 문을 열고 닫는 역할을 수행합니다.

### 2. 시리얼 통신 (Serial Communication)
Arduino는 자체적으로 인증 판단을 내리지 않고, Python 백엔드 서버와 시리얼 통신(UART/USB)으로 데이터를 주고받습니다.
- **데이터 전송:** NFC 태그가 태그되거나 키패드로 번호가 입력되면, 해당 이벤트를 시리얼 포트를 통해 서버로 전송합니다.
- **명령 수신:** 서버에서 인증 성공(문 열림 명령) 또는 실패(에러 메시지 및 경고음 명령)를 시리얼로 수신합니다.

### 3. 실패 시 거부 (Fail-Safe) 로직 설계
보안 시스템에 있어 가장 중요한 원칙인 **Fail-Safe**를 기반으로 작성되었습니다.
- 시스템 전원 문제, 서버와의 통신 두절, 알 수 없는 에러가 발생한 경우 무조건 '잠금(Lock)' 상태를 유지하도록 설계되어 외부의 불법 침입을 차단합니다.
- 서버로부터 명시적인 허가 명령이 떨어졌을 때만 릴레이를 활성화합니다.

---

## 작동 프로세스 개요

1. `MFRC522` 모듈이 NFC 카드를 감지합니다.
2. Arduino가 카드의 UID 값을 시리얼 통신으로 Python 서버에 전송합니다.
3. Python 서버에서 데이터베이스 확인 및 안면 인식 2차 인증을 진행합니다.
4. 모든 인증이 성공하면 Python 서버에서 "OPEN" 명령을 Arduino로 전송합니다.
5. Arduino가 릴레이 모듈을 일정 시간 활성화하여 잠금을 해제합니다.
6. 만약 인증 실패 또는 타임아웃 발생 시, 시스템은 초기 상태로 돌아가며 문은 잠긴 상태를 유지합니다.

하드웨어 연결 및 배선 정보에 대해서는 [하드웨어 배선 및 사양](../system_docs/hardware_spec.md) 문서를 참조하십시오.
