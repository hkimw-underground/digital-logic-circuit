# 세부 개발 프롬프트 02: 아두이노 정밀 제어 (담당자: 조희은)

## 1. 단계 목적
이 단계에서는 하드웨어 계층의 안정성과 반응 속도를 극대화합니다. 입력 장치(NFC, 키패드)의 간섭을 최소화하고, 서버의 명령에 따라 릴레이를 정확하게 제어하는 펌웨어를 완성합니다.

## 2. To-Do 리스트
1. **비차단형(Non-blocking) 타이머 구현:** `delay()` 함수 대신 `millis()`를 사용하여 릴레이가 열려 있는 동안에도 키패드와 NFC 입력을 처리할 수 있도록 펌웨어를 수정합니다.
2. **입력 데이터 정규화:** 키패드 입력 시 디바운싱(Debouncing) 처리와 NFC UID의 고정 길이 전송을 통해 시리얼 데이터의 신뢰성을 높입니다.
3. **상태 피드백 강화:** 릴레이 작동 직후 `DOOR_OPENED`, `DOOR_CLOSED` 신호를 서버로 전송하여 시스템 상태 동기화를 보장합니다.
4. **저전력 및 안정화:** 장시간 구동 시에도 안정적으로 동작할 수 있도록 메모리 누수를 점검하고 워치독(Watchdog) 타이머 설정을 검토합니다.

## 3. 개발 가이드 (Vibe)
- 하드웨어 제어는 0.1초의 지연도 사용자 경험에 큰 영향을 미칩니다. 반응 속도를 최우선으로 최적화하십시오.
- 핀 맵 충돌이 발생하지 않도록 하드웨어 사양 문서를 엄격히 준수합니다.

## 4. AI 명령 예시
"`arduino/doorlock.ino` 파일의 릴레이 제어 부분을 `millis()` 기반으로 변경해줘. 문이 열려 있는 3초 동안에도 새로운 NFC 태그나 비밀번호 입력이 들어오면 이를 무시하지 않고 시리얼로 즉시 보낼 수 있는 구조가 필요해. 그리고 `MFRC522`와 `Keypad` 라이브러리의 핀 설정이 겹치지 않는지 다시 한번 확인해줘."
