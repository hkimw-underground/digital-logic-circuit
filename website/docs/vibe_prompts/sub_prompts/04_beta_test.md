# 세부 개발 프롬프트 04: 베타 테스트 및 취약점 분석 (담당자: 송현호)

## 1. 단계 목적
이 단계에서는 실제 사용자의 관점에서 시스템의 맹점을 찾아내고, 보안 취약점을 공격적으로 분석합니다. 기술적인 결함뿐만 아니라 사용자 경험(UX) 측면의 불편함을 도출합니다.

## 2. To-Do 리스트
1. **스푸핑(Spoofing) 공격 테스트:** 사진, 태블릿 영상, 정교한 가면 등을 이용해 얼굴 인식 보안이 뚫리는지 확인하고, YOLOv8의 객체 감지(휴대폰 차단) 기능을 검증합니다.
2. **비정상 입력 테스트:** 무차별 대입(Brute-force) 공격 시나리오를 작성하고, 시스템이 설정된 락다운(Lockdown) 모드로 정상 진입하는지 확인합니다.
3. **엣지 케이스 점검:** 시리얼 케이블이 갑자기 분리되거나, 데이터베이스 파일이 손상되었을 때의 시스템 복구력을 테스트합니다.
4. **UX 개선사항 도출:** 웹 GUI의 로그 가독성, 사용자 등록 과정의 복잡도 등을 점검하여 개선 리스트를 작성합니다.

## 3. 개발 가이드 (Vibe)
- "안 되는 이유"를 찾는 데 집중하십시오. 모든 예외 상황은 문서화되어 개발팀에 공유되어야 합니다.
- 테스트 결과는 객관적인 지표(성공/실패 횟수, 지연 시간 등)와 함께 기록합니다.

## 4. AI 명령 예시
"현재 시스템의 보안 설정을 바탕으로, 공격자가 수행할 수 있는 5가지 주요 시나리오를 작성하고 각 시나리오별 방어 대책을 `SECURITY_ANALYSIS.md`에 정리해줘. 특히 얼굴 인식 단계에서 스마트폰 화면으로 사진을 보여줄 때 이를 감지하는 YOLO 로직이 얼마나 정확한지 테스트할 수 있는 방법론을 제안해줘."
