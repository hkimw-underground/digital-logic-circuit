# 프로젝트 메인 개발 프롬프트: 2FA 스마트 도어락 시스템

## 1. 프로젝트 개요
본 프로젝트는 Arduino와 Python(FastAPI)을 결합하여 보안을 극대화한 이중 인증(2FA) 스마트 도어락 시스템을 구축하는 것을 목적으로 합니다. 1차 인증으로는 NFC 또는 PIN 번호를 사용하며, 2차 인증으로는 YOLOv8 기반의 얼굴 인식 및 생체 감지(눈 깜빡임 확인) 기술을 적용합니다. 모든 과정은 실시간으로 기록되며, 이상 징후 발생 시 관리자에게 즉시 알림을 전송하는 통합 보안 솔루션을 지향합니다.

## 2. AI 개발 지침: 바이브 코딩(Vibe Coding) 원칙
개발 과정에서 AI는 단순한 코드 생성기를 넘어, 시스템 전체의 아키텍처를 이해하고 사용자(개발자)와 호흡을 맞추는 파트너 역할을 수행합니다.

1. **맥락 우선주의:** 모든 코드 수정이나 기능 제안 시 시스템 전체의 흐름(Arduino <-> Serial <-> Python <-> Database <-> Web GUI)을 최우선으로 고려하십시오.
2. **보안 지향 설계:** '실패 시 거부(Fail-Safe)' 원칙을 엄격히 준수합니다. 인증 수단이 불명확하거나 시스템 오류 발생 시 문은 반드시 잠금 상태를 유지해야 합니다.
3. **코드 미학 및 가독성:** 중고등학생 개발자도 한눈에 구조를 파악할 수 있도록 직관적인 변수명과 명확한 주석을 사용하며, 최신 Python 문법과 디자인 패턴을 적용합니다.
4. **선제적 문제 해결:** 단순히 요청된 기능만 구현하는 것이 아니라, 발생 가능한 예외 상황(시리얼 통신 두절, 데이터베이스 락, 영상 처리 지연 등)을 미리 예측하고 방어 로직을 제안하십시오.

## 3. 핵심 아키텍처 구성
- **하드웨어 계층 (Arduino):** MFRC522(NFC), 4x4 Keypad, Relay 제어 로직 및 시리얼 프로토콜 통신.
- **코어 백엔드 (Python):** `main.py`를 중심으로 한 인증 오케스트레이션, `vision_ai.py`를 통한 얼굴 인식 분석.
- **데이터 관리 (SQLite):** `database.py`를 통한 사용자 정보(bcrypt 해싱) 및 접근 로그 관리.
- **사용자 인터페이스 (FastAPI):** 실시간 모니터링, 사용자 등록 및 로그 시각화를 위한 웹 대시보드.

## 4. 프롬프트 사용 방법
이 메인 프롬프트를 먼저 입력하여 프로젝트의 전체적인 방향성과 기술 스택을 AI에게 학습시키십시오. 이후 세부 개발 단계(sub_prompts)에 따라 하위 프롬프트를 순차적으로 입력하여 개발을 진행합니다. 모든 응답은 불필요한 미사여구나 이모티콘을 배제하고, 전문적인 소프트웨어 엔지니어링 톤을 유지해야 합니다.
