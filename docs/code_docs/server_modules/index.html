서버 모듈 설명 (Python Backend)

2FA 스마트 도어락 시스템의 백엔드 서버는 Python으로 구현되어 있으며, FastAPI 프레임워크를 기반으로 합니다. 주요 모듈은 server/ 디렉토리 하위에 위치하며, 각 모듈의 역할과 기능은 다음과 같습니다.

핵심 모듈​

1. main.py​

서버의 진입점이자 메인 오케스트레이터입니다. FastAPI 앱 인스턴스를 생성하고 시작합니다. 백그라운드 태스크로 시리얼 통신(아두이노)을 모니터링하여 NFC 태그나 키패드 입력 등의 하드웨어 이벤트를 처리합니다.

  • 하드웨어 이벤트를 받아 적절한 인증 로직(vision_ai.py 등)을 호출합니다.
  • 인증 성공 또는 실패 결과를 아두이노로 피드백합니다.

2. web_app.py​

FastAPI 기반의 웹 인터페이스 및 API 엔드포인트를 제공합니다.

  • /, /dashboard 등의 라우트를 통해 관리자 웹 UI(HTML 템플릿)를 서빙합니다.
  • 사용자 등록, 로그인, 출입 기록 조회 등의 API(api/ 경로)를 처리합니다.

3. database.py​

SQLite 데이터베이스와의 상호작용을 담당합니다.

  • 사용자 정보(users 테이블) 및 출입 기록(access_logs 테이블)을 관리합니다.
  • bcrypt를 사용하여 비밀번호(PIN)를 안전하게 해싱하여 저장 및 검증합니다.
  • verify_password 함수는 타이밍 공격(Timing Attack)을 방지하기 위해 일정한 검증 시간을 가지도록 설계되었습니다.

4. vision_ai.py​

YOLOv8 모델 및 face_recognition 라이브러리를 사용한 얼굴 인식 및 생체 감지(눈 깜빡임, Liveness) 로직을 포함합니다.

  • 카메라 영상에서 얼굴을 식별하고, 등록된 사용자 데이터베이스와 대조합니다.
  • 2차 인증(2FA)의 핵심 컴포넌트로 활용됩니다.
  • 이전에는 Pickle 포맷으로 얼굴 인코딩을 처리했으나 보안상의 이유로 현재는 FACE128F64: 형태의 안전한 프리픽스 포맷을 사용합니다.

5. notifier.py​

시스템 내 주요 이벤트 발생 시 외부로 알림을 전송하는 모듈입니다.

  • 예를 들어, 인증 실패, 비정상적 접근 시도 등 보안 위협이 감지되면 Discord 웹훅(Webhook) 등을 통해 관리자에게 비동기적으로 실시간 알림을 보냅니다.
  • 서버의 메인 스레드 블로킹을 막기 위해 알림 전송은 별도의 스레드에서 수행됩니다.

6. config.py​

서버의 환경설정 변수들을 중앙집중적으로 관리합니다.

  • 데이터베이스 경로, 시리얼 포트 번호, Discord 웹훅 URL 등의 설정값을 로드합니다.

7. mock_arduino.py​

실제 아두이노 하드웨어 없이 소프트웨어적으로 도어락의 동작(NFC 태그, PIN 입력 등)을 시뮬레이션하기 위한 인터랙티브 테스트 도구입니다. CI/CD 환경이나 개발 중에 하드웨어 연동 없이 로직을 검증할 때 유용합니다.
