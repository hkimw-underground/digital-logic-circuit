# [입문자 가이드] 세상에서 가장 쉬운 2FA 스마트 도어락 정복하기

## 1. 이게 대체 뭔가요? (초간단 요약)
이 프로젝트는 **'우리 집 문을 철통 보안으로 지키는 똑똑한 경비원'**을 만드는 것입니다.
단순히 열쇠로 여는 게 아니라, 두 가지 관문을 통과해야 문이 열립니다.

1.  **제1관문:** 카드키(NFC)를 대거나 비밀번호(PIN)를 입력합니다.
2.  **제2관문:** 카메라가 당신의 얼굴을 보고, 진짜 사람인지(눈을 깜빡이는지) 확인합니다.

이 두 가지를 모두 통과해야만 "철컥!" 하고 문이 열리는 시스템입니다.

---

## 2. 어려운 용어, 비유로 이해하기

소프트웨어 개발이 처음인 친구들을 위해 어려운 단어들을 일상적인 말로 바꿔볼게요.

### 2FA (Two-Factor Authentication)
- **원래 뜻:** 이중 인증
- **쉬운 설명:** 현관문을 열 때 **'열쇠도 돌리고 + 지문도 찍는'** 것처럼 두 번 확인하는 거예요. 하나가 털려도 다른 하나가 지켜주니까 훨씬 안전하죠!

### bcrypt (비크립트)
- **원래 뜻:** 비밀번호 암호화 알고리즘
- **쉬운 설명:** 여러분의 비밀번호를 **'절대 풀 수 없는 암호문'**으로 바꾸는 기계예요. 해커가 우리 데이터베이스를 훔쳐가도 여러분의 원래 비밀번호가 뭔지는 절대 알 수 없게 만들죠.

### YOLO (You Only Look Once)
- **원래 뜻:** 실시간 객체 탐지 인공지능
- **쉬운 설명:** 카메라로 들어오는 영상에서 **'이건 얼굴이야!', '이건 스마트폰이야!'** 하고 순식간에 찾아내는 인공지능 탐정이에요. 사진을 내밀어서 속이려고 하면 바로 잡아낸답니다.

### SQLite (에스큐엘라이트)
- **원래 뜻:** 가벼운 관계형 데이터베이스
- **쉬운 설명:** 우리 시스템의 **'기록장'**이에요. 누가 언제 들어왔는지, 어떤 카드가 등록되어 있는지 깔끔하게 표로 정리해서 저장해두는 똑똑한 수첩이죠.

## 3. 시스템은 어떻게 작동하나요? (시각화)

```mermaid
sequenceDiagram
    participant User as 사용자 (나)
    participant HW as 아두이노 (입력기)
    participant Server as 파이썬 서버 (두뇌)
    participant AI as 비전 AI (눈)
    participant Door as 도어락 (릴레이)

    User->>HW: NFC 태그 또는 PIN 입력
    HW->>Server: "이 사람 카드번호는 A1B2예요"
    Server->>Server: 데이터베이스에서 카드 주인 찾기

    alt 1차 인증 성공
        Server->>AI: "카메라 켜서 얼굴 좀 확인해줘!"
        AI->>User: 얼굴 스캔 및 눈깜빡임 확인
        alt 진짜 사람이고 등록된 얼굴임
            AI->>Server: "확인 완료! 주인님 맞아요."
            Server->>HW: "문 열어줘! (OPEN_DOOR)"
            HW->>Door: 릴레이 작동 (철컥!)
        else 가짜(사진) 또는 모르는 사람
            AI->>Server: "수상해요! 문 열어주면 안 돼요."
            Server->>Server: 침입 로그 기록 및 알림 전송
        end
    else 1차 인증 실패
        Server->>Server: "모르는 카드예요!" (거부)
    end
```

## 4. 나도 할 수 있다! 실행 순서

### 1단계: 준비물 챙기기
- 아두이노 보드 (Uno 또는 R4)
- NFC 리더기 (MFRC522)
- 4x4 키패드
- 릴레이 모듈 및 도어락
- 웹캠 (또는 노트북 내장 카메라)

### 2단계: 아두이노에 생명 불어넣기
`arduino/doorlock.ino` 파일을 아두이노에 업로드하세요. 이제 아두이노는 카드를 읽고 비밀번호를 받을 준비가 됩니다.

### 3단계: 파이썬 서버 깨우기
터미널(또는 CMD)을 열고 아래 명령어를 입력하세요.
```bash
# 환경 설정 (처음 한 번만)
pip install -r requirements.txt

# 서버 실행
python3 server/main.py
```

### 4단계: 웹 화면 접속하기
인터넷 브라우저를 켜고 `http://localhost:8000`에 접속해보세요. 실시간으로 누가 오는지, 얼굴은 잘 인식되는지 한눈에 볼 수 있습니다!
