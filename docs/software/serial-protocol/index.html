Serial Protocol

Communication between the Arduino and the Backend Server utilizes a simple plaintext serial protocol over USB (9600 Baud).

Message Formats​

Arduino → Server​

EventString FormatExample
System ReadySYSTEM_READYSYSTEM_READY
NFC Card TapUID:<hex_string>UID:A1B2C3D4
PIN EntryPIN:<string>PIN:1234

Server → Arduino​

CommandAction
UNLOCKInstructs the Arduino to pull the relay pin HIGH/LOW for the configured unlock duration (e.g., 3000ms).
DENYExplicit rejection command. Triggers an error beep or LED blink (if implemented). Relay state remains locked.

Security Note: This protocol is currently unencrypted. See the Security section regarding physical access limitations.
