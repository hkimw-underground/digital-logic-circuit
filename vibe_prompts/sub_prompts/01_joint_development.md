# 세부 개발 프롬프트 01: 1차 공동 개발 및 전체 시스템 빌드업

## 1. 단계 목적
이 단계에서는 모든 개발팀원이 협력하여 시스템의 뼈대를 구축합니다. 하드웨어와 소프트웨어의 통신 규격을 확립하고, 기본 인증 흐름이 중단 없이 이어지도록 통합하는 데 집중합니다.

## 2. To-Do 리스트
1. **시리얼 프로토콜 확립:** Arduino와 Python 서버 간의 메시지 규격(`WAKEUP:NFC`, `WAKEUP:PW`, `OPEN_DOOR`)을 최종 확정하고 연동 테스트를 수행합니다.
2. **데이터베이스 스키마 구축:** 사용자 정보, 얼굴 인코딩 데이터, 접근 로그를 저장할 SQLite 테이블 구조를 설계하고 초기화 스크립트를 작성합니다.
3. **비전 AI 파이프라인 연결:** YOLOv8 모델을 로드하여 영상 내 얼굴을 검출하고, face_recognition 라이브러리를 통해 등록된 사용자와 대조하는 기초 로직을 완성합니다.
4. **통합 인증 흐름 구현:** 1차(NFC/PIN) 인증 성공 시에만 2차(Vision) 인증으로 전환되는 워크플로우를 `main.py`에 구현합니다.

## 3. 개발 가이드 (Vibe)
- "일단 돌아가게 만든다(Make it work)"는 마음가짐으로 시작하되, 코드 간의 결합도는 낮추어 이후 개별 개발 단계에서 수정이 용이하게 합니다.
- 모든 기능은 독립적인 유닛 테스트가 가능하도록 함수화하고 모듈화하십시오.
- 하드웨어가 없는 팀원을 위해 `DOORLOCK_VISION_MOCK`과 같은 모의(Mock) 실행 환경을 반드시 포함합니다.

## 4. AI 명령 예시
"현재 시스템의 아키텍처를 기반으로, `main.py`에서 시리얼 입력을 받아 `database.py`를 조회하고, 성공 시 `vision_ai.py`의 인증 함수를 호출하는 전체 제어 루프를 작성해줘. 시리얼 통신은 비동기 처리가 불가능한 환경을 고려하여 효율적인 폴링(Polling) 또는 스레딩 방식을 선택하고, 예외 발생 시 로그를 남기는 것을 잊지 마."
